            Ограничения памяти (сборка)
            
    
              
              
              
            
    
            
    Добавляются в сборку как section code/ram/stack: программа, которая не помещается, не соберётся.
              Пусто — размер по умолчанию PVM; блок «память» в проекте важнее. Симулятор получает те же стек и RAM.
    
          
    
          
    
            Команды
            
            
            
          
    
          
    
            Переменные PazzleIDE для команд
            
    В командах пишите ${имя}, пути с пробелами берите в кавычки: "${hex}".
              Те же значения процесс получает в окружении (PAZZLE_HEX и т. д.), системные переменные — ${env:ИМЯ}.
              Щелчок по имени вставляет его в поле, где стоит курсор.
